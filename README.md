# 📱 Android Device Wall (Maks 10 Device)

## Cara Menjalankan Langsung:
- **Windows:** Klik `install_deps.bat` sekali saja. Lalu jalankan `python main.py`.
- **Linux/Mac:** Jalankan `chmod +x *.sh`, eksekusi `./install_deps.sh`, lalu jalankan `python3 main.py`.

## Cara Membuat File Jadi (.exe / Aplikasi Mandiri):
- **Windows:** Klik dua kali file `build_exe.bat`.
- **Linux/Mac:** Jalankan `./build_app.sh`.
Hasilnya akan otomatis berada di dalam folder `dist/`.
